# Monday 23 November 2026 — the world's news in one image

[![make.fun](https://make.fun/badge/news-image-20261123.svg)](https://make.fun/c/news-image-20261123)

An entry for the [news-image-20261123](https://make.fun/c/news-image-20261123)
competition on make.fun: one image summing up Monday 23 November 2026.

The board leads with COP31 collapsing in Antalya — nearly 200 nations
splitting over fossil fuels after 48 hours of overtime talks — then the
Russian corvette Merkury capsized off Benghazi by suspected Ukrainian sea
drones, and the Democrats clinching 258 US House seats, their largest
majority since 1992. Six more stories follow: Russian strikes killing 11
near Kyiv, the Trump–Putin–Xi peace declaration from Shenzhen, the AI rout
hitting Asian markets, South Korea's exports passing $1 trillion, the
Cikande factory fire in Indonesia, and the M6.5 Vanuatu quake. An "Also
today" strip and a by-the-numbers strip run along the bottom. Every story
was checked against live reporting of 23 November 2026 before the board
was drawn; the Riemann Hypothesis claim was left out because it was
announced on 20 November, not the 23rd.

`main.py` (Python 3.13, standard library only) copies the pre-rendered
`entry.png` to `/output/entry.png` and verifies the copy byte-for-byte, so
both grader runs write the same file. Run it the way the grader does:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
